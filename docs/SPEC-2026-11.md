# 보라핀 설계서 2026-11 — 한 권(가이드북↔여행책) · 심는 지도 · 여기 뭐야

> 설계: Claude Fable 5.1 (2026-10-26, 사용자 윤영상과 대화로 결정) · 구현: Claude Opus 5.5 (주말)
> 이 문서는 구현 담당이 **사용자에게 다시 묻지 않고** 만들 수 있을 만큼 적는 것이 목표다. 여기 없는 결정은 "덜 만드는 쪽"으로 한다.

## 0. 인계 메모 (구현 담당이 먼저 읽을 것)

1. 읽는 순서: `CLAUDE.md` → `docs/ROADMAP.md`(순서·상태표) → 이 문서 → `docs/REVIEW-2026-10.md`(디자인 D 토큰·평가 기준).
2. 확인 명령: `npm run typecheck` · `npm run test:unit` · `npx tsx scripts/ask-test.ts` · `npx tsc --noEmit -p tsconfig.scripts.json` · (worker/) `npx tsc --noEmit` · `npx vite build --outDir /tmp/claude-0/dist`. 에뮬레이터·화면 시험은 CI에서만 돈다(작업 공간에서 jar를 못 받음).
3. 규칙: 버그는 테스트부터(실패 기록 → 고침 → 통과 기록). 비용 0. 앱이 쓰는 동안 바깥 API를 부르지 않는다(자료는 CI가 미리). 가격 숫자 없음, 바뀌는 정보엔 '기준 달'과 '떠나기 전 확인'. 새 탭·새 메뉴 없음. 화면 글은 쉬운 우리말, 단추 동사와 알림 동사를 맞춘다(`times()`·`withRo()`).
4. 만들다 만 화면은 `src/lib/flags.ts`로 숨긴다: `FLAGS.book`, `FLAGS.garden`, `FLAGS.capsule` 세 개를 새로 두고 끝나면 지운다.
5. 커밋: 작은 단위로, 메시지는 우리말 한 줄 + 트레일러(`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` 형식과 `Claude-Session:` 줄은 그 세션 안내를 따른다). `git push origin HEAD:main`은 돌고 있는 CI를 취소하므로 작업 중 스냅샷은 `wip/…` 브랜치로.
6. 멈출 때: ROADMAP의 15·16·13번 '다음 할 일'을 갱신하고 커밋.
7. **사용자에게 물어야 할 것은 두 가지뿐**: (a) 첫 해외 가이드북 도시, (b) 시화 꽃 스티커 그림체 — 3종 시안을 먼저 보여 주고 고르게 한다. 그 밖엔 이 문서대로.

## 1. 배경과 방향

- 2026-10-25 해외 유료 여행 앱 조사(Polarsteps·Journi·Trip Atlas·Fog of World·Wanderlog·Flighty·PeakFinder 등)의 결론: 사람들은 **완성된 결과물**(포토북), **수집의 재미**, **현장의 궁금증 즉시 해결**에 지갑을 연다.
- 사용자 결정: ① 여행 한 권 — 채택 · ② 옛 사진으로 지난 여행 복원 — **미룸** · ③ 여기 뭐야 — 채택(13번에 포함) · ④ 수집 — 채택하되 **Fog of World 아류 금지**, 안개 대신 **심는 지도**.
- 가이드북: 사용자는 여행마다 시판 가이드북(프렌즈·셀프트래블·리얼·디스이즈·에이든)을 사서 **넓게 훑고 몇 곳만 추린다**. 보라핀은 "훑기는 폰에서, 종이엔 추린 20쪽"으로 그 습관을 그대로 옮긴다. 국내는 시판 책이 없는 시·군이 대부분인데 보라핀은 160칸 자료가 이미 있다 → **국내판 먼저**.
- 수익 방향(지금 만들지 않음, 구조만 미리): 도시 가이드북은 **하나의 묶음 단위**(`src/data/guides/<도시>.json`)로 두어 나중에 "도시 한 권" 판매가 가능하게. 티켓·투어 단추는 검색 링크로 두되 나중에 제휴 링크로 바꾸면 결제 시스템 없이 첫 수익. 공개 링크 뒷표지에 '보라핀' 이름 한 줄.
- 혼자·친구 그룹도 같은 규칙으로 돌아가야 한다(부부 전용 규칙 금지). 둘의 색은 **덤**이지 조건이 아니다.

## 2. 묶음 A — 한 권 (가이드북 ↔ 여행책)

### A0. 한 문장
여행 하나가 **한 권**이다. 예정(`planned`)이면 가이드북, 다녀오면(`done`) 여행책. 같은 화면·같은 렌더러, 상태에 따라 쪽이 바뀐다. 연말엔 '2026년 한 권'이 그해 여행책들을 묶는다.

### A1. 자료 모델 (순수 함수, 시험 가능)
`src/lib/book.ts`
```ts
export type BookMode = 'guide' | 'album';
export interface BookPage { kind: 'cover'|'glance'|'map'|'day'|'see'|'eat'|'shop'|'phrases'|'basics'|'packing'|'blank'|'stamps'|'numbers'|'back'; ...내용 }
export interface Book { mode: BookMode; season: 'spring'|'summer'|'autumn'|'winter'; title: string; pages: BookPage[]; credits: Credit[] }
export function buildBook(input: {
  trip: Trip; recs: PlaceRec[]; notes: Note[]; photos: Photo[]; plan: PlanItem[];
  home: Home | null; members: string[]; extraPhotos?: { url: string; w: number; h: number }[];
  region: (p: Place) => RegionData; // tour.json·festivals·abroad·world·phrases를 읽는 어댑터
  now?: Date;
}): Book
```
- `season`은 `trip.when.m`(없으면 첫 사진 촬영 달, 그래도 없으면 `now`)로 `seasonOf()`.
- 사진은 저장된 `_l`(긴 변 1600px)을 쓴다. `extraPhotos`는 **이 책에만 끼우는 사진**(A5 참고).
- 글·동행 이름은 공개 사본(`SharedTrip`)에 없으므로 공개 링크 책에서는 빈 칸으로 둔다(기존 규칙 유지).
- 빈 자료는 **쪽을 만들지 않는다**(빈 카드 금지). 단 `blank`(손글씨 칸)는 가이드북에 항상 1쪽.

### A2. 쪽 구성
**가이드북(guide)**
| # | 쪽 | 내용 | 자료 |
|---|---|---|---|
| 1 | cover | 대표 사진 전면, 제목(Jua), 날짜(Gaegu), 사람 색 점 | 대표 사진 규칙은 PlaceSheet의 ScenicPhoto와 같음 |
| 2 | glance | 며칠(`nightsDays`), 집에서 가는 길·시간(HomeRoute), 좋은 달인지·그달 한 줄, D-day | home.ts·stopover.ts·world.json(`best`,`why`)·seasons.json |
| 3 | map | 국내: KoreaMosaic SVG에 들를 칸 표시 / 해외: 나라 윤곽(SpotMap 자료) + 도시 점 | kr-svg.json·geodata |
| 4… | day | 하루 한 쪽: 일정 항목(시간·이름·한 줄) + 그 장소 사진 | PlanItem·tour.json 사진 |
| … | see | 볼거리·축제(그 달) 10개 안팎, 사진·2줄·동네 | RegionInfo·festivals·tour.json / 해외: guides/<도시>.json |
| … | eat | 대표 먹거리 + 먹거리 거리·시장 (개별 식당 없음) | RegionInfo 먹거리 / world `eat` / guides |
| … | shop | 쇼핑 거리·몰·시장 + 기념품 품목 | guides(해외만; 국내는 생략) |
| … | phrases | 해외만: 현지어 30문장 중 사용자가 별표한 것 우선 10개, 없으면 기본 10개 | phrases.json |
| … | basics | 해외: 전압·콘센트·통화·시차·입국 메모·유심·환전·치안 메모 + **기준 달·떠나기 전 확인** / 국내: 날씨 한 줄 | world.json·abroad.json·travelinfo.json |
| … | packing | 준비물 네모 체크 | trip.packing |
| 끝-1 | blank | "여기서 한 줄" 손글씨 줄 8개 | — |
| 끝 | back | 티켓·투어 단추 3개(앱에서만, 인쇄엔 주소 글자) · 사진 출처 · '보라핀에서 만들었어요' | credits |

**여행책(album)**
| # | 쪽 | 내용 |
|---|---|---|
| 1 | cover | 같은 표지 + 도장 "다녀왔어요 · 2026.10"(`.stamp`) |
| 2 | map | 다녀온 칸이 밝아진 모자이크 + 들른 순서 점선(MapReplay 자료) |
| 3… | day | 하루 한 쪽: 폴라로이드 1~2장 + 둘의 한 줄 평(각자 색, Gaegu) + 글(Note) |
| … | stamps | 이 여행에서 **처음** 간 칸들의 도장(`stats.cellVisits` 이전 값과 비교) |
| … | numbers | 새로 채운 칸 수, 움직인 거리(places 좌표 합), 몇 번째 여행, 사진 수 — 큰 숫자 카드 금지, 손글씨 한 줄들로 |
| 끝 | back | 핀이 한마디(`whatsNew` 문장 재사용) · 출처 · 보라핀 |

**연간 한 권(year)**: 추억 돌아보기의 결산(`year-review`)에 '올해 한 권으로 보기' 단추 → 표지(그해 사진 콜라주 4장) + 지도 + 여행마다 1쪽(표지 축소판) + 도장 모음 + 숫자. 1차 범위에서는 **있으면 좋고 없어도 됨** — 시간이 남을 때.

### A3. 둘러보기 → 추리기(담기)
- 국내: 지역 창(RegionInfo·TourSpots)의 관광지·볼거리·먹거리·축제 항목마다 **'담기'** 칩. 예정 여행이 있으면 그 여행의 일정(PlanItem, `day:null`)으로, 없으면 가고 싶은 곳(Wish, `spotName`)으로. 알림: '담았어요'. 이미 담긴 건 '담겼어요' 비활성.
- **아내 의견(10-26)**: 볼거리·먹거리·대표 사진을 눌러 뜨는 지도 고르기 창(`MapChoice.tsx`)에도 `가고 싶어요` 단추(하트)를 둔다 — "나중에 가고 싶은 곳을 일일이 검색 안 해도 되게". 누르면 Wish(`place`=그 칸, `spotName`=이름, `wantedBy`=나) → '가고 싶은 곳에 담았어요'. 이미 있으면 '담겨 있어요'. 지도 설정이 네이버·카카오(창 없이 바로 열림)여도 볼거리·먹거리·사진은 `search:true`라 창이 뜨므로 단추가 보인다. 관광지 카드(TourSpots)는 카드 모서리에 작은 하트 칩. **이건 순서 0으로 먼저** 만든다(한 권과 무관하게 바로 쓸모 있음).
- 해외: CityInfo에 같은 칩. 자료는 `guides/<도시>.json`이 있으면 그걸, 없으면 world.json의 `see`/`eat`만.
- **인쇄되는 가이드북의 day·see·eat 쪽은 담은 것만** 싣는다. 담은 게 없으면 see·eat은 자료의 앞 6개로 채우고 머리에 "아직 고르지 않았어요 — 지역 창에서 담아 두면 여기 실려요".

### A4. 화면과 길
- 길: `/trips/:id/book` (TripDetail 안의 라우트, 아래 메뉴 없이 전체 화면).
- 들어가는 단추 **하나**: TripDetail 제목 아래, 예정이면 `가이드북 보기`, 다녀왔으면 `한 권으로 보기` (`data-testid="book-open"`). 새 탭·메뉴 없음.
- 책장: 세로로 넘기는 쪽들(`.book-page`, 화면에선 폰 너비, 인쇄에선 A5). 위에 `PDF로 저장` · `링크 보내기`(기존 ShareLinkCard 재사용) · 닫기.
- `PDF로 저장` = `window.print()`. 첫 번만 기기별 한 줄 안내(`localStorage 'borapin:print-hint'`): iOS "공유 → 프린트 → 미리보기를 길게 눌러 PDF", 안드로이드 "인쇄 → PDF로 저장", PC "대상: PDF로 저장". 안내는 알림(toast)이 아니라 책 위 한 줄(인쇄엔 안 나옴).
- 인쇄 CSS: `@page { size: A5; margin: 0 }` · `.book-page { break-after: page; width: 148mm; height: 210mm }` · 색 인쇄 보장 `print-color-adjust: exact` · 사진은 `object-fit: cover` · 아래 메뉴·상단 단추 `display:none` · 글꼴은 앱의 Jua·Gaegu woff2 그대로.
- 오프라인: 책은 폰 안 자료로만 만들므로 오프라인에서도 열린다. 위키미디어 사진은 SW 캐시에 있는 것만 나오고 없으면 색종이 바탕.

### A5. 사진 끼우기 (저장 없이)
- 책 위 `사진 끼우기` → `<input type=file multiple accept=image/*>` → `URL.createObjectURL` → `extraPhotos`로 day 쪽에 날짜 순 배치(EXIF 날짜는 기존 `photos.ts`의 읽기 재사용). **서버에 올리지 않는다.** 화면에 "이 사진은 책에만 들어가고 저장되진 않아요".
- 떠날 때 끼운 사진이 있으면 `useBusy`로 새 버전 교체를 미루고, 뒤로가기엔 확인 한 번.

### A6. 공개 링크
- 기존 `/s/:token`(SharedTripPage)에 `?book=1`이면 책 보기로. `buildShared`에 책이 필요한 최소 자료가 빠져 있으면(일정 항목·대표 사진 키) 보태되, 글·동행·메모는 계속 넣지 않는다.
- 뒷표지 '보라핀에서 만들었어요' 링크는 공개 책에만.

### A7. 디자인 (디자인 D 그대로, 종이책답게)
- **여행마다 계절 옷**: 바탕 색종이 토큰 `--paper-spring #FFE9F0`, `--paper-summer #E3F7F2`, `--paper-autumn #FFE8D2`, `--paper-winter #F3F4FA`. 외곽선·그림자는 공통(`--outline`, `--shadow`).
- 한 쪽에 하나만 크게. 여백 12mm. 사진은 글보다 크게. 테이프(`.tape`)·폴라로이드(`.pola`)·도장(`.stamp`)·손글씨(`.hand`)·제목(`.jua`) 재사용.
- 금지: 그라데이션, 큰 숫자 카드, 아이콘 카드, 회색 그림자. 숫자는 손글씨 문장으로("새로 채운 칸 세 개").
- 사진 출처: credits 쪽에 위키미디어·관광공사 출처 자동(기존 /credits 자료 함수 재사용).

### A8. 티켓·투어 단추 (해외·국내 둘 다, 뒷표지와 glance 쪽)
- 공개 API 없음(2026-10 확인). **그 도시 검색 페이지로 가는 링크 3개**: 마이리얼트립·KKday·클룩. 주소 형식은 `src/lib/placeApps.ts`에 함수로 두고(`tourLinks(cityName)`), **구현 때 실제로 열어 보고 확인**한다(검색 주소가 바뀌면 여기 한 곳만 고침). 국내는 관광공사 자료의 체험·레포츠를 먼저 보여 주고 단추는 아래에.
- 인쇄에서는 단추 대신 주소 글자를 작게.

## 4. 묶음 C — 심는 지도

### C1. 자라는 규칙 (`src/lib/garden.ts`, 순수 함수)
```ts
export type Stage = 'seed' | 'sprout' | 'flower' | 'tree';
export interface Plant { code: string; stage: Stage; colors: string[]; rings: number[]; flower?: string }
export function growth(code: string, x: { visits: number; years: number[]; recsBy: string[]; notesBy: string[]; photos: number; books: number }, tones: (name: string) => string): Plant
```
| 단계 | 조건 | 모양 |
|---|---|---|
| seed | 핀만 | 흙 위 점 |
| sprout | **누구든** 한 줄 평·글·사진 중 하나 | 잎 두 장, 남긴 사람 색 |
| flower | 한 줄 평·글·사진 중 **둘 이상 종류** 또는 둘 이상 사람 | **그 고장의 시화**가 핀다 |
| tree | 이 칸이 들어간 여행책(한 권)이 한 번이라도 열렸거나 PDF로 저장됨(`books ≥ 1`) | 열매 달린 나무 |
- `rings` = 다녀온 해들(나이테). 다시 가면 나이테 하나.
- `colors` = 남긴 사람들의 색(`toneOf`). 1명이면 그 색, 둘 공간에서 둘 다면 보라(`--both`), 3명 이상이면 꽃잎마다 색. **사람 수로 규칙이 바뀌지 않는다.**
- 숙제 금지: 포인트·연속 출석·미션 없음. 알림은 아래 C5의 한 달 1회뿐.

### C2. 시화 도감 (`src/data/flowers.json`)
- 160칸 각각의 공식 시화(市花·군화)를 손으로 정리: `{ "11110": { "flower": "개나리", "icon": "forsythia" }, ... }`. 겹치는 꽃이 많아 아이콘은 20~25종이면 된다(개나리·철쭉·진달래·동백·매화·목련·장미·국화·벚꽃·배꽃·연꽃·산수유·해당화·백일홍·무궁화·살구꽃·복숭아꽃·유채·참꽃·메밀꽃·코스모스·수선화·작약·능소화 등). 출처는 각 시·군 누리집(공개 정보) — 파일 머리에 `updated`.
- 아이콘 `public/art/flowers/<icon>.svg`: 디자인 D 스티커체(두꺼운 외곽선, 파스텔 채움, 24×24 기준). **그림체 시안 3종을 먼저 사용자에게 보인다**(인계 메모 7-b). 보라 그림체와 같은 손으로 보여야 한다.
- 추억 돌아보기에 '모은 꽃' 한 면(`data-testid="flower-book"`): 핀 꽃은 색으로, 안 핀 꽃은 회색 선만. "160송이 중 18송이". 새 메뉴 없음.
- 시험 `tests/unit/flowers.test.ts`: 160칸 모두 있음, 모든 icon 파일이 존재, 꽃 이름이 2~5글자.

### C3. 지도 표시 (`MapView.tsx`)
- 전국 보기: 칸 바탕은 지금처럼 보라 농도(`fillExpr`). **한 사람만 남긴 칸은 그 사람 색 테두리**(`feature-state: half = 'pink'|'blue'|...`), 둘 다면 테두리 없음.
- 확대(zoom ≥ 8) 또는 칸을 눌러 시트가 열리면: 식물 아이콘(단계별 SVG 4개 + 꽃은 시화 아이콘) + 나이테 숫자 + 시화 이름 한 줄. 지도 위 아이콘은 `symbol` 레이어 하나(이미지 스프라이트 등록), 나이테는 시트에서만.
- PlaceSheet 머리(도장 옆)에 식물 한 줄: "꽃이 피었어요 · 개나리 · 2019 · 2024".

### C4. 꽂는 순간
- 새 칸이 처음 채워지면 시트의 도장 움직임 뒤에 새싹이 돋는 0.5초(`.sprout-in`, `prefers-reduced-motion`이면 생략). `celebrate.whatsNew`에 "경상북도 첫 칸이에요!" 같은 도(道) 첫 칸 문장 추가.

### C5. 다음 한 칸 · 한 칸 남았어요
- 홈 `headline` 아래 한 줄(`data-testid="next-cell"`): "집에서 가장 가까운 빈 칸은 양평이에요 · 차로 1시간 10분". 집이 없으면 안 보임. 계산은 `stats.cellVisits`·`cellPlanned` 제외 + `REGIONS` 좌표 직선거리 → 가장 가까운 3개 중 `stopover.ts`의 차 시간으로 1개. 눌러 지역 창.
- 캐리어 스티커(도 단위)에 한 칸 남으면 꼬리표 `한 칸 남았어요`(`.sticker-tag`).
- 핀이가 이 한 줄을 **한 달에 한 번만** 말풍선으로(`localStorage 'borapin:next-cell-said' = YYYY-MM`). 그 외엔 조용히 한 줄만.

### C6. 타임캡슐 한 줄
- `Note`에 `openAt?: string`(YYYY-MM-DD)과 `opened?: Record<uid, true>` 추가. 글 쓰기 화면(NotesTab)에 작은 토글 `1년 뒤 우리에게` → `openAt = 오늘+1년`(날짜 바꾸기 가능).
- `openAt`이 미래인 글은 목록에서 **봉투**로 보이고 내용은 안 보인다(화면 규칙; 보안 규칙은 그대로 — 같은 공간 사람끼리 비밀은 아니므로). 날짜가 되면 홈에 봉투 카드(`data-testid="capsule"`) → 열면 그 여행 표지·한 줄 평과 함께 글이 보이고 `opened[uid]=true`. 단추: `봉하기` → '봉했어요', `열어 보기` → '열었어요'.
- 규칙 시험: `openAt`·`opened`가 있는 글도 기존 notes 규칙으로 쓰고 읽히는지(필드 허용 목록이 있으면 보탠다). 단위: 봉투 판정(`isSealed(note, now)`), 열릴 날 계산.
