## 1. 배경과 방향

- 2026-10-25 해외 유료 여행 앱 조사(Polarsteps·Journi·Trip Atlas·Fog of World·Wanderlog·Flighty·PeakFinder 등)의 결론: 사람들은 **완성된 결과물**(포토북), **수집의 재미**, **현장의 궁금증 즉시 해결**에 지갑을 연다.
- 사용자 결정: ① 여행 한 권 — 채택 · ② 옛 사진으로 지난 여행 복원 — **미룸** · ③ 여기 뭐야 — 채택(13번에 포함) · ④ 수집 — 채택하되 **Fog of World 아류 금지**, 안개 대신 **심는 지도**.
- 가이드북: 사용자는 여행마다 시판 가이드북을 사서 **넓게 훑고 몇 곳만 추린다**. 보라핀은 **사용자가 세우는 계획이 곧 책**이 되게 한다 — 담은 곳을 앱이 채우고 사람이 고친다(A9). 도시 자료를 미리 써 두지 않는다. 국내는 160칸 자료가 이미 있어 채워지는 양이 많고, 해외는 링크·위키백과 요약으로 채운다.
- 수익 방향(지금 만들지 않음, 구조만 미리): 결제 지점은 **'내 가이드북 PDF·인쇄'**(완성된 결과물). 티켓·투어 단추는 검색 링크로 두되 나중에 제휴 링크로 바꾸면 결제 시스템 없이 첫 수익. 공개 링크 뒷표지에 '보라핀' 이름 한 줄.
- 혼자·친구 그룹도 같은 규칙으로 돌아가야 한다(부부 전용 규칙 금지). 둘의 색은 **덤**이지 조건이 아니다.

## 2. 묶음 A — 한 권 (가이드북 ↔ 여행책)

### A0. 한 문장
여행 하나가 **한 권**이다. 예정(`planned`)이면 가이드북, 다녀오면(`done`) 여행책. 같은 화면·같은 렌더러, 상태에 따라 쪽이 바뀐다. 연말엔 '2026년 한 권'이 그해 여행책들을 묶는다.

### A1. 자료 모델 (순수 함수, 시험 가능)
`src/lib/book.ts`
```ts
export type BookMode = 'guide' | 'album';
export interface BookPage { kind: 'cover'|'glance'|'map'|'day'|'see'|'eat'|'shop'|'phrases'|'basics'|'packing'|'blank'|'stamps'|'numbers'|'back'; ...내용 }
export interface Book { mode: BookMode; season: 'spring'|'summer'|'autumn'|'winter'; title: string; pages: BookPage[]; credits: Credit[] }
export function buildBook(input: {
  trip: Trip; recs: PlaceRec[]; notes: Note[]; photos: Photo[]; plan: PlanItem[];
  home: Home | null; members: string[]; extraPhotos?: { url: string; w: number; h: number }[];
  region: (p: Place) => RegionData; // tour.json·festivals·abroad·world·phrases를 읽는 어댑터
  now?: Date;
}): Book
```
- `season`은 `trip.when.m`(없으면 첫 사진 촬영 달, 그래도 없으면 `now`)로 `seasonOf()`.
- 사진은 저장된 `_l`(긴 변 1600px)을 쓴다. `extraPhotos`는 **이 책에만 끼우는 사진**(A5 참고).
- 글·동행 이름은 공개 사본(`SharedTrip`)에 없으므로 공개 링크 책에서는 빈 칸으로 둔다(기존 규칙 유지).
- 빈 자료는 **쪽을 만들지 않는다**(빈 카드 금지). 단 `blank`(손글씨 칸)는 가이드북에 항상 1쪽.

| 끝 | back | 핀이 한마디(`whatsNew` 문장 재사용) · 출처 · 보라핀 |

**연간 한 권(year)**: 추억 돌아보기의 결산(`year-review`)에 '올해 한 권으로 보기' 단추 → 표지(그해 사진 콜라주 4장) + 지도 + 여행마다 1쪽(표지 축소판) + 도장 모음 + 숫자. 1차 범위에서는 **있으면 좋고 없어도 됨** — 시간이 남을 때.

### A3. 함께 찾기 → 담기 (여행지를 열 때, 그 자리에서)
사용자 결정(10-26): **잘 안 바뀌는 기본정보만 미리 저장하고, 나머지는 여행지를 열 때 함께 찾아 계획을 세우고, 그에 따라 동선을 정리해 가이드북으로 만든다.** **지역별로 미리 만들어 두고 내려받는 묶음은 없다** — 미리 두는 건 기본정보 일부(좋은 달·날씨·옷차림·전압·통화·시차·말·대표 이름 몇 개)뿐이고, 볼 것·먹을 것·살 것 후보는 여는 순간 뒷단이 받아 온다(하루 캐시는 같은 도시를 여러 번 열 때 다시 받지 않으려는 것이지 미리 만든 자료가 아니다). 세 층:
1. 기본정보(미리): world.json·국내 160칸·seasons·travelinfo. 바뀌는 것(입국·경보·환율)은 지금처럼 매일 자동(abroad-build).
2. **함께 찾기(열 때)**: 도시 카드(CityInfo)·지역 창(RegionInfo) 아래 '같이 찾아볼까요?' 묶음 — 칩 `볼 것 / 먹을 것 / 살 것 / 할 것`, 항목마다 이름·한 줄·동네·`지도에서 확인`(MapChoice)·**담기**.
   - 국내 출처: tour.json(관광지·연관·근처)·festivals·trend(붐빔). 이미 폰 안.
   - 해외 출처: **위키보이지(Wikivoyage, CC BY-SA)** 영어판 목록(See/Do/Eat/Buy의 listing: 이름·좌표·한 줄). 물어보기 뒷단 `GET /find?city=<en>&kind=see|do|eat|buy` 가 그때 받아 파싱해 돌려준다(KV 캐시 1일, 실패하면 503 → 화면은 "지금은 못 찾았어요 — 링크를 붙여넣어도 돼요"). 우리말 한 줄은 Workers AI가 **번역만**(지어내기 금지: 원문 한 줄이 없으면 빈 줄). 가격 기호+숫자는 걸러 낸다. 출처는 credits에 자동.
   - 밖에서 찾은 곳: 네이버·구글 지도 링크 붙여넣기(`placeLookup.ts` 기존) → 사진·주소·좌표.
   - 맛집은 **앱이 고르지 않고 후보를 보여 주며 사람이 고른다.** 항목마다 '지도에서 확인'이 붙어 영업 여부는 그 자리에서 본다.
3. 동선 정리(A12) → 가이드북(A2).

- '담기'의 행선지: 예정 여행이 있으면 그 여행의 일정(PlanItem, `day:null`, 좌표·한 줄·출처 포함)으로, 없으면 가고 싶은 곳(Wish, `spotName`)으로. 알림 '담았어요', 이미 있으면 '담겼어요' 비활성.
- **아내 의견(10-26)**: 볼거리·먹거리·대표 사진을 눌러 뜨는 지도 고르기 창(`MapChoice.tsx`)에도 `가고 싶어요` 단추(하트)를 둔다 — "나중에 가고 싶은 곳을 일일이 검색 안 해도 되게". Wish(`place`=그 칸, `spotName`=이름, `wantedBy`=나) → '가고 싶은 곳에 담았어요'. 관광지 카드(TourSpots)는 모서리에 작은 하트 칩. **순서 0으로 먼저.**
- 핀이는 담을 때마다 "근처에 ○○도 있어요" **하나만**(국내 tour 연관·근처 / 해외 같은 동네의 아직 안 담은 항목).
- 인쇄되는 가이드북의 day·see·eat·shop 쪽은 **담은 것만**. 담은 게 없으면 그 쪽은 만들지 않고 glance 쪽에 "같이 찾아 담아 두면 여기 실려요" 한 줄.
- 뒷단 시험 `tests/unit/worker-find.test.ts`: 파싱(이름·좌표·한 줄), 가격 걸러 내기, 캐시 적중, 실패 503, 멤버 아니면 401(guard 공통). 화면 시험: 에뮬레이터에서는 뒷단을 모킹한 고정 응답 3건으로 담기까지.

### A4. 화면과 길
- 길: `/trips/:id/book` (TripDetail 안의 라우트, 아래 메뉴 없이 전체 화면).
- 들어가는 단추 **하나**: TripDetail 제목 아래, 예정이면 `가이드북 보기`, 다녀왔으면 `한 권으로 보기` (`data-testid="book-open"`). 새 탭·메뉴 없음.
- 책장: 세로로 넘기는 쪽들(`.book-page`, 화면에선 폰 너비, 인쇄에선 A5). 위에 `PDF로 저장` · `링크 보내기`(기존 ShareLinkCard 재사용) · 닫기.
- `PDF로 저장` = `window.print()`. 첫 번만 기기별 한 줄 안내(`localStorage 'borapin:print-hint'`): iOS "공유 → 프린트 → 미리보기를 길게 눌러 PDF", 안드로이드 "인쇄 → PDF로 저장", PC "대상: PDF로 저장". 안내는 알림(toast)이 아니라 책 위 한 줄(인쇄엔 안 나옴).
- 인쇄 CSS: `@page { size: A5; margin: 0 }` · `.book-page { break-after: page; width: 148mm; height: 210mm }` · 색 인쇄 보장 `print-color-adjust: exact` · 사진은 `object-fit: cover` · 아래 메뉴·상단 단추 `display:none` · 글꼴은 앱의 Jua·Gaegu woff2 그대로.
- 오프라인: 책은 폰 안 자료로만 만들므로 오프라인에서도 열린다. 위키미디어 사진은 SW 캐시에 있는 것만 나오고 없으면 색종이 바탕.

### A5. 사진 끼우기 (저장 없이)
- 책 위 `사진 끼우기` → `<input type=file multiple accept=image/*>` → `URL.createObjectURL` → `extraPhotos`로 day 쪽에 날짜 순 배치(EXIF 날짜는 기존 `photos.ts`의 읽기 재사용). **서버에 올리지 않는다.** 화면에 "이 사진은 책에만 들어가고 저장되진 않아요".
- 떠날 때 끼운 사진이 있으면 `useBusy`로 새 버전 교체를 미루고, 뒤로가기엔 확인 한 번.

### A6. 공개 링크
- 기존 `/s/:token`(SharedTripPage)에 `?book=1`이면 책 보기로. `buildShared`에 책이 필요한 최소 자료가 빠져 있으면(일정 항목·대표 사진 키) 보태되, 글·동행·메모는 계속 넣지 않는다.
- 뒷표지 '보라핀에서 만들었어요' 링크는 공개 책에만.

### A7. 디자인 (디자인 D 그대로, 종이책답게)
- **여행마다 계절 옷**: 바탕 색종이 토큰 `--paper-spring #FFE9F0`, `--paper-summer #E3F7F2`, `--paper-autumn #FFE8D2`, `--paper-winter #F3F4FA`. 외곽선·그림자는 공통(`--outline`, `--shadow`).
- 한 쪽에 하나만 크게. 여백 12mm. 사진은 글보다 크게. 테이프(`.tape`)·폴라로이드(`.pola`)·도장(`.stamp`)·손글씨(`.hand`)·제목(`.jua`) 재사용.
- 금지: 그라데이션, 큰 숫자 카드, 아이콘 카드, 회색 그림자. 숫자는 손글씨 문장으로("새로 채운 칸 세 개").
- 사진 출처: credits 쪽에 위키미디어·관광공사 출처 자동(기존 /credits 자료 함수 재사용).

### A12. 동선 정리 (`src/lib/route.ts`, 순수 함수)
```ts
export function arrange(items: PlanItem[], opts: { days: string[]; stay?: { lat: number; lng: number } | null; pinned?: (i: PlanItem) => boolean }): PlanItem[]
```
- 좌표 있는 항목을 **날짜 수만큼 가까운 것끼리 묶고**(k-평균 대신 단순: 가장 먼 둘을 씨앗으로 한 탐욕 묶기, 하루 항목 수 균형 ±1), 하루 안에서는 숙소(`stay`, 없으면 그날 첫 항목)에서 가까운 순(최근접 이웃 + 2-opt 한 번).
- 시간이 적힌 항목(`time`)은 **못 박고** 나머지를 그 사이에 넣는다. 좌표 없는 항목은 그날 끝에.
- 사람이 끌어 바꾼 뒤에는 다시 자동으로 섞지 않는다: PlanTab의 `다시 정리` 단추를 눌렀을 때만 `arrange`를 다시 돌리고, 돌리기 전 순서를 되돌리기(undo)로 남긴다.
- 하루 이동 거리(직선 합)가 국내 60km·해외 도시 안 15km를 넘으면 그날 머리에 "이날은 좀 많아요" 한 줄(숫자 단정 없이).
- 국내 교통편 시간은 9번(FLAGS.transitRoute) 뒤에 붙인다. 그전엔 거리와 `지도 길찾기` 단추(MapChoice).
- 가이드북 day 쪽은 이 순서 그대로, map 쪽은 하루마다 색이 다른 점선.
- 시험 `tests/unit/route.test.ts`: 2일·5곳 묶기, 못 박은 항목 자리 보존, 좌표 없는 항목 끝, 끌어 바꾼 뒤 보존, 거리 경고 문턱.

### C1. 자라는 규칙 (`src/lib/garden.ts`, 순수 함수)
```ts
export type Stage = 'seed' | 'sprout' | 'flower' | 'tree';
export interface Plant { code: string; stage: Stage; colors: string[]; rings: number[]; flower?: string }
export function growth(code: string, x: { visits: number; years: number[]; recsBy: string[]; notesBy: string[]; photos: number; books: number }, tones: (name: string) => string): Plant
```
| 단계 | 조건 | 모양 |
|---|---|---|
| seed | 핀만 | 흙 위 점 |
| sprout | **누구든** 한 줄 평·글·사진 중 하나 | 잎 두 장, 남긴 사람 색 |
| flower | 한 줄 평·글·사진 중 **둘 이상 종류** 또는 둘 이상 사람 | **그 고장의 시화**가 핀다 |
| tree | 이 칸이 들어간 여행책(한 권)이 한 번이라도 열렸거나 PDF로 저장됨(`books ≥ 1`) | 열매 달린 나무 |
- `rings` = 다녀온 해들(나이테). 다시 가면 나이테 하나.
- `colors` = 남긴 사람들의 색(`toneOf`). 1명이면 그 색, 둘 공간에서 둘 다면 보라(`--both`), 3명 이상이면 꽃잎마다 색. **사람 수로 규칙이 바뀌지 않는다.**
- 숙제 금지: 포인트·연속 출석·미션 없음. 알림은 아래 C5의 한 달 1회뿐.
