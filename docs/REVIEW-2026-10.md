## 5. 디자인 (귀염뽀짝) — 시안 캔버스 'A/B/C/D'
- 결정 필요: A 종이 스크랩북 / B 말랑 스티커북 / C 둘의 교환일기 / **D 통합안(추천)** = B 뼈대 + C 색 규칙 + A 순간.
- D의 규칙: 구조(카드·단추·탭·메뉴)는 윤곽선 2px + 색종이 그림자 + 둥근 제목 글꼴(주아). 사람이 드러나는 곳(아바타·하트·핀·한 줄 평·D-day)은 핑크=보라·파랑=영상·보라색=둘. 사진·추억의 순간에만 폴라로이드·테이프·손글씨(개구)·도장. 한 화면에 '순간' 요소는 하나. 목록은 평평하게.
- 글꼴: 본문 프리텐다드 유지. 주아·개구는 OFL, 글자 조각으로 쪼개 앱 안에 둠(바깥 서비스 없음), 짧은 글에만.
- 공통 결함 12 (방향과 무관하게 고침): 눌림 표시 없음(styles.css:35·189·256·548·704) / 켜진 하트 4색 / `#33248a` 12곳·`#b4472c` 3곳·지도·공유카드·모자이크 색 통일 / 홈 카드 안 카드·반경 역전(Home.tsx:125-130) / 시트·메뉴·토스트 움직임·배경막 / reduced-motion 빠진 곳 / 10px 이하 글자 / 5탭 줄바꿈 / 글자 기호를 아이콘으로(⛶·▶) / 상태 막대 색·로딩 화면 보라·iOS 시작 그림 / 사진 툭 뜸(흐린 미리보기) / 지도 로딩 자리.
- 화면별 시안 순서(컨셉 확정 뒤): 홈 → 여행 목록 → 여행 상세(예정/다녀온) → 지도+지역 시트 → 가고 싶은 곳 → 기록 남기기 → 추억 → 우리 공간 → 로그인·환영.
