# 보라핀 사진함 (PC 프로그램) 설계안

작성 2026-11-07 · 상태: 제안 (만들기 전)

## 1. 왜 만드나

- 사진은 폰·카메라에서 계속 쌓이는데 정리가 안 된다. 여행이 끝나면 수백 장이 그대로 남는다.
- 보라핀은 폰에서 쓰는 앱이라 원본을 보관할 곳이 없다 (Firestore 무료 한도 1GiB, 사진은 긴 변 1600px·1MB 미만으로 줄여 저장).
- 바라는 것: **원본은 PC가 관리**하고, **보라핀에는 줄여서 자동으로 올라가고**, **쉬운 보정**과 **앨범처럼 보기·PDF 포토북**까지.

## 2. 해외 사례에서 배운 것

| 프로그램 | 잘하는 것 | 우리가 가져올 것 | 안 맞는 것 |
|---|---|---|---|
| Google Photos | 폰 자동 백업, 한 번 눌러 보정, '그날의 추억', 앨범 → 포토북 주문, 검색 | 한 번 눌러 보정, 날짜별 타임라인, 앨범에서 바로 책 만들기 | 원본이 구글 서버에(용량 유료), 폴더 정리 개념 없음 |
| Apple 사진 | 원본은 내 기기, 보정은 원본을 건드리지 않음(언제든 되돌림), 추억 영상 | 되돌릴 수 있는 보정(사이드카), 기기 안 원본 | 애플 기기 안에서만 |
| Lightroom | 되돌릴 수 있는 보정, 프리셋, 카탈로그(원본은 그대로 두고 목록만) | 카탈로그 방식, 프리셋 3~4개 | 전문가용·월 요금·복잡함 |
| Mylio Photos | **PC가 원본 보관소**, 클라우드 없이 기기끼리 맞춤, 중복 찾기, 달력 보기 | 원본은 PC·폰엔 줄인 사본, 중복 정리, 달력 | 유료, 자체 생태계 |
| Immich | 셀프 호스팅, 폰 자동 올리기, 타임라인·앨범·공유, 얼굴·의미 검색 | 타임라인·앨범 화면의 짜임, '여러 해 전 오늘' | 서버(항상 켜 둔 컴퓨터)가 필요 |
| PhotoPrism | 기존 폴더 구조 유지, 지도 보기, 기본 편집기 | 폴더를 깨뜨리지 않기, 지도 보기 | 폰 자동 올리기 없음 |
| digiKam | 무료·강력(태그·얼굴·중복) | 중복 판별 방식(해시+닮은 그림) | 화면이 어려움 |

핵심 교훈 다섯 가지:
1. **원본은 내 컴퓨터, 바깥엔 줄인 사본** — Mylio·Apple 방식. 우리 비용 0 원칙과 맞다.
2. **매일 쓰는 보정은 한 번 누르기** — 슬라이더는 뒤에 숨긴다 (Google Photos).
3. **보정은 원본을 건드리지 않는다** — 옆에 작은 설정 파일(사이드카)만 두고, 내보낼 때 적용 (Lightroom·Apple).
4. **쌓이기만 하는 문제의 답은 '중복·연사 정리'와 '여행 단위 묶기'** — 비슷한 사진 10장 중 1장만 고르게 돕는다.
5. **앨범에서 몇 번 눌러 책이 나와야** 쓴다 (Google·Apple의 포토북).

## 3. 한 줄 정의

> PC에 두는 작은 프로그램. 정한 폴더를 지켜보다가 새 사진이 오면 **정리하고(날짜·여행별 폴더, 중복 제거) → 고르고(연사·흔들림 정리) → 줄여서 보라핀에 올린다.** 보정과 앨범·포토북은 이 프로그램 안에서 한다.

이름(가칭): **보라핀 사진함**.

## 4. 지키는 것

- 비용 0: 서버 없음. 프로그램은 PC에서만 돌고, 보라핀(Firestore)에는 지금과 같은 방식으로 줄인 사진만 올린다.
- 원본은 절대 지우거나 덮어쓰지 않는다. 옮길 때도 '복사 후 확인' 뒤에만 원래 자리를 비운다(사용자가 켠 경우).
- 보정은 되돌릴 수 있다 (원본 + 사이드카).
- 보라핀 무료 한도를 눈에 보이게: 올리기 전에 **"지금 420MB / 1GB"** 같은 계기판을 보여 주고, 넘칠 것 같으면 올리지 않는다.
- 로그인은 보라핀과 같은 구글 계정. 비밀번호를 저장하지 않는다.
- 혼자·둘·여럿 모두: 공간(space)에 속한 사람이면 누구나 쓸 수 있다.

## 5. 어떻게 생겼나 (화면)

왼쪽 좁은 줄에 네 칸: **받은 편지함 · 사진 · 앨범 · 올리기**. 나머지는 사진이 크게.

### 5-1. 받은 편지함 (새로 들어온 사진)
- 지켜보는 폴더에 새 사진이 오면 여기 쌓인다. (폰 → PC로 오는 길: 아이클라우드 사진(Windows용 iCloud 포함), 삼성 갤러리 PC 연결, 카카오톡 'PC로 보내기', USB, 카메라 SD카드)
- 프로그램이 먼저 해 두는 것:
  - **중복 제거**: 같은 파일(해시)과 닮은 사진(지각 해시, 연사)을 묶어 "비슷한 사진 7장 → 가장 선명한 1장 추천".
  - **날짜·자리 읽기**: EXIF 촬영 시각·GPS. 없으면 파일 날짜(보라핀처럼 '추정' 표시).
  - **여행 맞추기**: 보라핀의 여행 날짜·장소와 견줘 "11월 7~9일 사진 183장 → '통영·남해 드라이브'로" 제안. 맞지 않는 사진은 '일상'으로.
- 한 화면에서 **"정리하기"** 한 번: 원본을 `사진/2026/2026-11-07 통영·남해/`처럼 옮기고(복사 뒤 확인), 중복은 `사진/정리함/중복/`으로 치운다.

### 5-2. 사진 (타임라인)
- Google Photos처럼 날짜별 격자. 여행 기간은 머리띠가 여행 이름으로 바뀐다.
- 위에 달력 띠(보라핀 피드와 같은 모양) — 달을 넘기며 바로 간다.
- 사진을 열면 크게 + 오른쪽에 정보(언제·어디·여행·보라핀에 올라갔는지).
- 보정은 여기서 바로 (5-4).

### 5-3. 앨범 · 포토북
- 여행마다 앨범이 자동으로 생기고, 직접 만든 앨범도 둔다.
- 앨범 표지·차례·사진 묶음을 넘기며 보는 '책 보기' 모드.
- **PDF로 저장**: 틀 세 가지(한 쪽 한 장 / 두 장 / 사진 + 한 줄). 한 줄은 보라핀의 사진 설명·며칠째 글·한 줄 평을 그대로 끌어온다. 종이 크기 A5·정사각 20cm, 인쇄용 300dpi는 **원본**으로 만든다(PC에 원본이 있어 가능한 장점). 인쇄소 주문은 PDF를 들고 가면 된다.

### 5-4. 보정 (쉬운 것만)
- 맨 앞 단추 하나: **자동 보정** (밝기·색온도·대비를 알아서). 누르고 있으면 전·후 비교.
- 그다음: 자르기·똑바로 세우기·회전, 밝기·대비·따뜻함·선명함 네 슬라이더, 필름 느낌 3가지(맑게·따뜻하게·흑백).
- 사람 얼굴 흐리기(공개 지도·공유에 올리기 전).
- 모두 원본은 그대로. `사진이름.jpg.borapin.json` 사이드카에 설정만 적고, 올리거나 내보낼 때 적용.

### 5-5. 올리기
- 규칙: 여행 하나에 **최대 60장**(보라핀 규칙), 하루에 최대 n장(기본 12). 연사·중복은 이미 걸러져 있다.
- 추천 고르기 → 사용자가 체크 → 올리기. 줄이는 규격은 지금 앱과 같게(긴 변 1600px·950KB 미만, 미리보기 400px). 보라핀 무료 한도가 60% 넘으면 1200px로 낮추기를 권한다.
- 자동 모드(선택): "새 여행 사진이 오면 추천만 해 두고, 내가 확인하면 올린다" / "밤 2시에 알아서 올린다". 기본은 확인 뒤 올리기.
- 올린 사진은 보라핀 피드·여행·추억에 지금처럼 보인다. 설명(한 줄)은 PC에서 써도 되고 폰에서 써도 된다.

## 6. 만드는 방식

| 항목 | 선택 | 이유 |
|---|---|---|
| 틀 | Tauri 2 (Rust + 웹 화면) | 설치 파일 10MB대, Windows·mac 둘 다, 보라핀 웹 코드(React·사진 줄이기·EXIF·Firebase SDK)를 그대로 씀. Electron보다 가볍고 무료 |
| 목록 | SQLite 한 파일 | 수만 장도 빠르게. 원본 폴더는 그대로 두고 목록만 (Lightroom 카탈로그 방식) |
| 사진 처리 | Rust 쪽: 해시·지각 해시·흔들림 점수·EXIF·크기 줄이기 | 수백 장도 몇 초 |
| 로그인 | 구글 로그인(시스템 브라우저 → 앱으로 돌아옴) | 비밀번호 저장 없음, 보라핀과 같은 계정·규칙 |
| 올리기 | 지금 앱과 같은 Firestore 문서(photos·photoData) | 규칙·화면을 바꾸지 않아도 됨 |
| 보정 | 화면은 캔버스(WebGL) 미리보기, 적용은 Rust | 슬라이더가 끊기지 않음 |
| PDF | 프로그램 안에서 생성(원본 해상도) | 외부 서비스 없음 |
| 배포 | GitHub Releases | 비용 0. 코드 서명이 없어 처음 실행 때 경고가 뜬다(안내문으로 넘긴다) |
| 폰 → PC | 운영체제의 사진 동기화 폴더를 지켜봄 | 우리가 폰 앱을 또 만들지 않는다 |

## 7. 자료 모양 (PC 쪽)

- `photos` : 파일 경로, 해시, 지각 해시, 촬영 시각, GPS, 폭·높이, 흔들림 점수, 묶음(연사) 번호, 여행 id, 올린 보라핀 사진 id, 사이드카 유무
- `trips` : 보라핀에서 읽어 온 여행(id·이름·날짜·장소) — 읽기 전용 사본
- `albums` : 직접 만든 앨범(이름·사진 순서·표지)
- 사이드카 `*.borapin.json` : `{ v:1, crop, rotate, auto:true, bright, contrast, warmth, clarity, preset, blurFaces:[...] }`

## 8. 단계

1. **정리함 (첫 주말)**: 폴더 지켜보기 → 중복·연사 묶기 → 여행 맞추기 → 날짜·여행 폴더로 정리 → 고른 뒤 올리기(계기판 포함). 이것만으로 '쌓이기만 하는 문제'가 풀린다.
2. **보정**: 자동 보정·자르기·네 슬라이더·필름 3종·얼굴 흐리기, 사이드카.
3. **앨범·포토북**: 타임라인·달력 띠, 여행 앨범, 책 보기, PDF 세 가지 틀.
4. **자동**: 무인 올리기 시간표, '여러 해 전 오늘' 알림(PC 알림), (선택) 얼굴 묶기 — PC 안에서만 도는 작은 모델, 바깥으로 보내지 않음.

## 9. 보라핀 앱 쪽에서 같이 고칠 것

- 사진 문서에 `from: 'desk'`와 사이드카 적용 여부 표시(폰에서 올린 것과 구분, 나중에 다시 올릴 때 중복 방지).
- 사진마다 `hash`(원본 해시)를 저장해 PC가 "이미 올라갔는지" 바로 알게.
- 공간 설정에 '사진함 연결됨 · 마지막 올림 11-07 02:10' 한 줄.
- 피드 달력 띠와 같은 부품을 PC 타임라인에도 쓴다(코드 공유).

## 10. 아직 정하지 않은 것 (사용자 확인)

- 원본을 **옮길지(폴더 정리)**, **그대로 두고 목록만** 만들지. 기본 제안: 그대로 두고 목록만 → '정리하기'를 누르면 옮김.
- 올리기 기본값: 여행당 60장 꽉 채울지, 하루 12장 정도로 아낄지(무료 한도 1GB ≈ 3,000장 안팎).
- 보정 결과를 보라핀에 올릴 때 **보정본**을 올릴지(기본) 원본 축소판을 올릴지.
- 포토북 종이 크기 기본값(A5 가로 제안).
- 프로그램 이름.
